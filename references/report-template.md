# 报告骨架模板（统一模板）

> 本文件是 `atoms/07-assemble-report.md` 的唯一骨架依据。所有项目跑完的报告，其章节树必须与本模板一致——数据段为空时省略正文，但标题层级与顺序不可变。
> 关键数字（版本号、行数、覆盖率、文件数、性能数据）必须标注来源：`（origin: repo_verified | repo_inferred | external_read | external_unread）`。未标注一律按 `repo_inferred` 对待。
> 性能/复杂度类结论若无实测（`metadata.capabilities.can_execute_commands=false` 或未运行实测），必须标注 `[推演]`，禁止以推演冒充实测。

## 文件集

| 文件 | 生成条件 | 对应数据源 |
|------|----------|-----------|
| `README.md` | 始终 | S1–S7 汇总 |
| `architecture-analysis.md` | 始终 | S3 数据流 + S4 模式 + S7 迁移建议 |
| `tech-stack.md` | 始终 | S1 技术栈 |
| `module-deep-dive.md` | 始终 | S2 模块清单 |
| `<target>-deep-dive.md` | 每 S5 目标一篇 | S5 输出 |
| `<feature>-reproduce.md` | 每 S6 功能一篇 | S6 输出 |
| `defect-scan.md` | 仅 S6B 启用 | S6B 输出 |

## README.md 固定章节树

```
# <项目名> 架构分析报告
## 项目身份卡片（名称/类型/一句话描述）
## ⏳ 待确认事项（可补做）      ← 仅 pending_confirmations 非空时
## 待办与可补做项（含未消费 [必挖] 信号及跳过理由）  ← 有 [必挖] 未消费时
## 架构全景图（Mermaid/ASCII）
## 技术栈速览（表格）
## 文档索引（链接其他报告文件）
## 分析元信息（日期/覆盖范围/未覆盖区域/token 或"未统计"）
```
